# CLI-Based-Task-Managing-System
📝 Task Manager CLI A simple and efficient command-line task manager built with Python. This tool helps you organize tasks, mark them as complete, and keep track of your productivity — all from the terminal.


📝✨ To‑Do List Tracker CLI ✨📝
Welcome to the To‑Do List Tracker App 🎯 — a Python‑powered command‑line tool designed to keep your life organized, one task at a time.
Forget bloated apps and endless tabs — this project is all about simplicity ⚡, speed 🚀, and productivity 📈 right inside your terminal.

🌟 Why This Project?
Managing tasks is something we all do every single day. Whether it’s:
- 📚 Students juggling assignments and deadlines
- 💻 Developers tracking coding goals
- 🛒 Everyday users keeping a shopping list
This CLI tool is your minimalist companion 🧑‍💻. It doesn’t overwhelm you with features you’ll never use. Instead, it gives you just what you need: Add ➕, Edit ✏️, Delete ❌, Show 👀, Exit 🚪.

⚙️ How It Works 🔧
- 📂 Persistent Storage → Tasks are saved in a JSON file (tasks.json) so they never disappear.
- 🖥️ Interactive Menu → A clean numbered menu guides you through options.
- 🔄 Continuous Loop → The app keeps running until you decide to exit.
- 🛡️ Error Handling → Invalid inputs? Missing files? The app handles it gracefully.

🛠️ Functions Breakdown 🧩
- save_tasks() 💾 → Saves your current list into tasks.json.
- load_tasks() 📂 → Loads tasks back when you restart.
- addtask(task_name) ➕ → Adds a new task to your list.
- deltask(task_name) ❌ → Deletes a task by name.
- editask(task_index, new_task) ✏️ → Replaces an existing task with something new.
- showtask() 👀 → Displays all tasks neatly numbered.
